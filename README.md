I build practical machine-learning and data systems end to end: from data preparation and experiments to evaluation, tests, APIs, and reproducible deployment. My current focus is Python engineering for ML, data, and retrieval systems.

- **[Road Object Detection](https://github.com/keeichii/road-object-detection)** — an individual two-model YOLO11n pipeline trained on GTSDB and KITTI, with a FastAPI demo and 84 automated tests. Test mAP50: **99.08%** for traffic signs and **86.52%** for pedestrians and vehicles.
- **[Alfa Hack RAG](https://github.com/keeichii/alfa)** — a GPU-first retrieval pipeline with text normalization, semantic chunking, multilingual embeddings, FAISS/BM25 retrieval, cross-encoder reranking, and Hit@5/Recall@K/MRR/NDCG evaluation.
